# assets

`layout.mjs` places `logo.png` (an emblem of 136 x 130 px, on a `#0B1119` background) on the logo page.
The author uses the Scania emblem, which is a trademark and therefore **not** part of this repository.
Put your own picture here as `logo.png` (or edit the `image` entry of the logo page in `layout.mjs`).
Files in this folder other than this one are ignored by git.
