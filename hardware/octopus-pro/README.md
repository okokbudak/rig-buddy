# BTT Octopus Pro V1.0.1 (STM32F446ZET6)

`Octopus_Pro_V1.0.1_F446_Datasheet.md` is a pin and electrical-limits reference written for this project
(Turkish). Each value says how reliable it is (official, schematic, derived).

BigTreeTech's own documents (user manual, pin diagrams) are not copied here; get them from the board's
repository: <https://github.com/bigtreetech/BIGTREETECH-OCTOPUS-Pro>.
This firmware is for the **V1.0.1 with the STM32F446ZET6**. The V1.1 boards have different pins.
