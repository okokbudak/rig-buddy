Serial gauges

Each device is one Arduino (or any board) on a COM port. Every channel is a formula; the numbers are rounded, joined with the separator and sent as one line, up to 25 times a second. Close SimHub's Custom Serial device for the same port first: only one program can use a COM port.

Formula help

Use property names from Live data and the usual operators: + - * / % **, < > == !=, && || !, a ? b : c.

Functions: round(x, d) floor ceil abs min(a, b…) max(a, b…) clamp(x, lo, hi) map(x, inLo, inHi, outLo, outHi) sqrt pow int if(c, a, b) format(x, d) pad(x, n).

Yes/no values count as 1/0. A missing property counts as 0. Examples: truck.speed.kph * 10, x.fuelPercent * 10, x.airBar * 100.
